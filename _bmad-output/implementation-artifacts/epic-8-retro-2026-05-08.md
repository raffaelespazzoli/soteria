## Successes

1. **100% completion, zero splits, zero spawned stories — three consecutive clean epics (7, 8, 9).** Scoping maturity from Epics 4-6 continues to pay off. AC counts stayed within the 10-cap (9, 6, 8, 7, 6).

2. **Cross-site safety mechanism (SitesInSync) is architecturally sound.** The three-story build-up (8.2 per-site discovery → 8.3 agreement gating → 8.4 console display) delivered a genuine product differentiator: executions are blocked when VMs disagree between sites. The first-deploy deadlock avoidance (WaitingForDiscovery proceeds instead of blocking) was caught during design, not during UAT.

3. **Story 8.1 — cleanest mechanical refactoring in project history.** Removed a spec field across ~54 files with zero debug issues. Go JSON decoder behavior (drop unknown fields) eliminated the need for strategy stripping, simplifying AC6 from code to automatic behavior.

4. **Derived state pattern in 8.5 was a lint-driven improvement.** Refactoring from `useEffect + setState` to `effectiveOptimisticExec = realActiveExec ? null : optimisticExec` avoids `react-hooks/set-state-in-effect`, eliminates a render cycle, and is more idiomatic React.

5. **Review process continues to catch real issues.** Story 8.4's 5 patches addressed: disabled tooltip on disabled control, undercounted mismatches from "and N more" cap, unmounted aria-live region, missing jest-axe states, hardcoded spacing tokens. All substantive.

6. **Strategic merge patch discipline held for concurrent two-controller writes.** Each site patches only its own SiteDiscovery field via `client.MergeFrom` — correct pattern for ScyllaDB eventual consistency.

7. **UAT methodology continued to mature.** Structured per-story test matrices with expected/actual/status columns, root cause analysis embedded in issue findings (UAT-8.001's analysis is precise and actionable).

## Challenges

1. **UAT-8.001 — SitesInSync race condition on first reconcile.** `evaluateSiteAgreement` reads `plan.Status.PrimarySiteDiscovery` before the active site writes it in the same reconcile cycle. Combined with UAT-8.002, this produces a permanently stuck `WaitingForDiscovery` state requiring pod restart. **Fix planned: option (b) — pass the about-to-be-written SiteDiscovery into the agreement check.**

2. **UAT-8.002 — Controller requeue is broken (pre-existing).** `RequeueAfter: 30s` doesn't fire. This is the first epic where reliable requeue is a dependency (SitesInSync must self-correct). Previous epics relied on watch-driven reconciles. **Under investigation: controller-runtime work queue / ScyllaDB CDC watch integration.**

3. **Console UAT tests (8.4, 8.5) remain PENDING — deferred again.** 10 test cases across two stories require live OpenShift Console. Console UAT has now been deferred for three consecutive epics (6, 7, 8). Scripted UAT flow (Epic 7 retro action items #7, #11) still not implemented.

4. **Interaction-pattern spike not executed for Epic 8.** Committed in Epic 6 retro, codified as rule #11 in project-context.md, still not done. The backend requeue pattern (UAT-8.002) would have been the highest-value spike target — not Console patterns.

5. **Review patches remain significant (~19 across 5 stories).** Consistent pattern across epics: ~85% first-attempt correctness with review catching edge cases. Patch taxonomy is stable: accessibility gaps, backward compatibility gaps, admission ordering gaps, platform integration gaps.

6. **UAT-8.004 — deploy script doesn't force pod restart.** `:latest` tag means `kubectl apply` is a no-op when deployment spec is unchanged. Requires manual `kubectl rollout restart` every deployment. Known since Epic 7.

---

## Key Insights

1. **"Requeue reliability is a prerequisite for self-healing status conditions."** SitesInSync, DisksConsistent, and replication health staleness all depend on periodic re-evaluation. Without reliable `RequeueAfter`, these conditions get stuck. The requeue investigation (UAT-8.002) is the highest-priority technical debt item.

2. **"Two-bug interactions are more dangerous than either bug alone."** UAT-8.001 (one-cycle stale read) + UAT-8.002 (no requeue) = permanent stuck state. Neither is critical in isolation. Testing should cover multi-cycle reconcile scenarios.

3. **"Mechanical refactoring stories are underrated for codebase hygiene."** Story 8.1's constant extraction simplified 4 function signatures, eliminated a validation check, and touched 54 files with zero issues. Small API simplifications compound.

4. **"Derived state > useEffect + setState for React lint compliance."** `const derived = realData ? null : localState` avoids synchronous setState in effects, eliminates a render cycle, and is testable without timing concerns. Worth codifying as a Console plugin pattern.

5. **"Review patches follow a predictable taxonomy."** Across 19 patches: accessibility (missing jest-axe states, aria-live), backward compat (nil guards, omitempty on booleans), admission ordering (preflight on block path), platform integration (disabled control tooltip). Story specs could include a checklist for these categories.
